# Biblioteca PHP Integration Melhor Envio

Essa é uma biblioteca criada para facilitar a integração com a Melhor Envio.

## O que é a melhor envio?

O Melhor Envio é uma plataforma de intermediação de fretes que permite a lojas virtuais e empresas comparar opções de envio e contratar serviços de diferentes transportadoras por meio de uma única plataforma.
